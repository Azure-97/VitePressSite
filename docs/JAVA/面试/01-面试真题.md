## HTTP状态码有哪些?都是什么含义?

HTTP状态码是一种三位数的代码，用于指示服务器对请求的响应状态。每个状态码都有特定的含义，通常分为五大类：

1. **成功响应（1xx - Informational）**：
    - 100（Continue）：表示请求已被服务器接收，用户可以继续发送请求的数据。
    - 101（Switching Protocols）：服务器已经和客户端协商同意使用不同的协议来完成后续的请求和数据传输。
2. **成功处理（2xx - Success）**：
    - 200 OK：请求已成功，常规响应。
    - 201 Created：请求已成功并创建了新的资源。
    - 202 Accepted：请求已被接受，但处理可能需要一段时间。
    - 203 Non-Authoritative Information：服务器返回当前有效数据的非最终响应，可能需要再次请求。
    - 204 No Content：请求已完成，但没有返回任何实体内容，常用于删除操作。
    - 206 Partial Content：只部分请求的内容已成功。
3. **重定向（3xx - Redirection）**：
    - 301 Moved Permanently：请求的资源已被永久移动到新的URL。
    - 302 Found：临时重定向，浏览器会自动跟随重定向。
    - 303 See Other：请求可以通过临时URI完成，为可缓存的资源。
    - 304 Not Modified：请求的资源未被修改，可使用缓存。
    - 307 Temporary Redirect：和302类似，但不建议缓存。
4. **错误请求（4xx - Client Error）**：
    - 400 Bad Request：请求无效，格式有误或数据丢失。
    - 401 Unauthorized：请求未经授权，需要提供身份验证。
    - 403 Forbidden：服务器拒绝请求，可能因为权限不足。
    - 404 Not Found：请求的资源未在服务器上找到。
    - 405 Method Not Allowed：请求方法（如GET、POST等）对于该资源是不支持的。
    - 408 Request Timeout：请求超时未完成。
    - 409 Conflict：资源冲突，服务器上有冲突的状态。
    - 410 Gone：请求的资源已永久删除，不可能再返回。
